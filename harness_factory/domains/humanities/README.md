## 中文速览
人文学域的目标是**让诠释建立在可核对的一手文本与显式的诠释立场之上**。以 L0–L5 编排 `core/`：L0 问题与文本（M7）、L1 汇整一手材料（M4/M6）、L2 细读与语境化（M1）、L3 诠释（声明视角，M3/M4）、L4 预备反读法（M3）、L5 写作（M7）。域特有风险：**以论带史**、**去语境化引用**、**时代错置**、**译本/版本混淆**、**把诠释当事实**。

---

## What this domain is for · 用途
Produce an interpretation grounded in primary sources — historical, philosophical, literary, philological — where the texts, editions, and interpretive lens are explicit, and counter-readings are honestly considered.

## Pipeline layers · 分层流水线
| Layer | Step | Core modules | Notes |
|---|---|---|---|
| L0 | Frame the question & texts | M0, M7 | scope, period, corpus |
| L1 | Assemble primary sources | M4, M6 | editions, provenance, archives |
| L2 | Close read & contextualize | M1 | language, genre, context |
| L3 | Interpret (state the lens) | M3, M4 | distinguish text from reading |
| L4 | Anticipate counter-readings | M3 | strongest opposing view |
| L5 | Write with provenance | M7, M4 | quote precisely; cite editions |

## Module combination · 模块组合
- **M0** — interpretation is not fact; mark the boundary explicitly.
- **M1** — hold only the texts and context under consideration.
- **M2** — long archival projects persist a reading ledger across sessions.
- **M3** — gate: quotes verified against the edition; counter-readings addressed.
- **M4** — claim ↔ text(edition, page) ledger; provenance for every quotation.
- **M6** — corpus/language tools minimal (concordance, OCR — verify against facsimile).
- **M7** — publications are reviewable; no auto-publish.

## Discipline-specific risks · 领域特有风险
- **Presentism / anachronism** — judging the past by present norms without saying so.
- **Decontextualized quotation**.
- **Edition / translation confusion**.
- **Reading into the text** what the argument needs.
- **Stating an interpretation as a fact**.
