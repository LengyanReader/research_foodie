# Domain · Education · 教育域
> Wiring `core/` modules into outcome-aligned curriculum and assessment design.
> 把 `core/` 模块接线成「以学习成果对齐」的课程与评估设计流程。
**Updated:** 2026-10-12

---

## 中文速览
教育域的目标是**让教学活动与评估都对齐到可测量的学习成果**。以 L0–L5 编排 `core/`：L0 界定学习成果（M7）、L1 逆向设计映射（M1/M3）、L2 材料与活动（M6）、L3 对齐的评估设计（M3）、L4 试教与测量（M3/M4）、L5 基于证据迭代（M5/M7）。域特有风险：**目标—活动—评估错位**、**只测低阶记忆**、**忽视学习者差异/无障碍**、**用分数替代证据**。

---

## What this domain is for · 用途
Design a course, unit, or training whose activities and assessments demonstrably align to stated learning outcomes, then improve it with measured evidence rather than opinion.

## Pipeline layers · 分层流水线
| Layer | Step | Core modules | Notes |
|---|---|---|---|
| L0 | Define learning outcomes | M0, M7 | observable, measurable verbs |
| L1 | Backward-design mapping | M3, M1 | outcome → evidence → activity |
| L2 | Build materials & activities | M6 | accessible, leveled |
| L3 | Design aligned assessment | M3 | matches outcome level |
| L4 | Pilot & measure | M3, M4 | pre/post; item analysis |
| L5 | Iterate with evidence | M5, M7 | revision log; no auto-publish |

## Module combination · 模块组合
- **M0** — a covered topic is not a learned outcome.
- **M1** — load the relevant outcomes and learner context, not the whole syllabus.
- **M2** — multi-term programs persist progress and revision history.
- **M3** — gate: alignment matrix outcome ↔ assessment ↔ activity is complete.
- **M4** — evidence for claims about learning (assessment data, not vibes).
- **M5** — course iteration is a human-gated improvement loop.
- **M7** — published materials are reviewable; learner data is protected.

## Discipline-specific risks · 领域特有风险
- **Constructive-alignment gaps** (test what you didn't teach).
- **Assessment confined to recall** despite higher-order outcomes.
- **Ignoring learner diversity / accessibility**.
- **Equating a test score with learning**.
