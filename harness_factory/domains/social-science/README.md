## 中文速览
社会科学域的目标是**让解释建立在理论、方法与证据三角互证之上**。以 L0–L5 编排 `core/`：L0 理论与研究问题（M7）、L1 方法选择（定量/定性/混合，M3）、L2 证据采集/来源（M4/M6）、L3 分析与三角互证（M3/M4）、L4 效度威胁与替代解释（M3）、L5 出稿（M7）。域特有风险：**以偏概全**、**选择性证据**、**概念/测量错配**、**反身性（研究者影响）未反思**、**伦理与知情同意**。

---

## What this domain is for · 用途
Move from a theoretical question to a defensible account of social phenomena — using quantitative, qualitative, or mixed evidence — where methods fit the question, conclusions are triangulated, and rival explanations are addressed.

## Pipeline layers · 分层流水线
| Layer | Step | Core modules | Notes |
|---|---|---|---|
| L0 | Theory & research question | M0, M7 | concepts defined, scope set |
| L1 | Select method (quant/qual/mixed) | M3 | fit method to question |
| L2 | Collect / source evidence | M4, M6 | interviews, archives, datasets |
| L3 | Analyze & triangulate | M3, M4 | converge across sources |
| L4 | Address validity threats | M3 | rival explanations, reflexivity |
| L5 | Report with provenance | M7, M4 | cite data, code, transcripts |

## Module combination · 模块组合
- **M0** — a compelling narrative is not evidence; triangulate.
- **M1** — load only the theoretical frame and evidence in scope.
- **M2** — longitudinal fieldwork spans sessions; keep coded data & audit trail.
- **M3** — gate: method-appropriate rigor (validity, reliability, reflexivity).
- **M4** — claim ↔ source(interview/archive/statistic) ledger; dates matter.
- **M6** — qualitative/quant tooling pinned (coding schema, survey instruments).
- **M7** — participant ethics and data-sharing are governed.

## Discipline-specific risks · 领域特有风险
- **Over-generalizing** from a single site/sample.
- **Cherry-picked evidence** supporting a prior conclusion.
- **Concept–measure mismatch**.
- **Unreflexive researcher influence**.
- **Ethics / consent / anonymization** failures.
