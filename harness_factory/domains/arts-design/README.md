# Domain · Arts & design · 艺术与设计域
> Wiring `core/` modules into intent-first creative work with critique and versioning.
> 把 `core/` 模块接线成「意图优先、以批评与版本管理」的艺术与设计流程。
**Updated:** 2026-10-12

---

## 中文速览
艺术设计域的目标是**让创作围绕明确的意图推进，并通过批评与版本记录而不丢失方向**。以 L0–L5 编排 `core/`：L0 陈述意图与约束（M7）、L1 参考与情绪板（M1）、L2 变体探索（M6）、L3 对照意图的批评（M3）、L4 精修与选择（M3/M2）、L5 交付与版本（M7）。域特有风险：**用产出量替代意图**、**失去版本/无法回退**、**反馈误读**、**交付不一致**。

---

## What this domain is for · 用途
Carry a creative brief to a delivered work — a design, an illustration, a composition — where intent is explicit, iterations are versioned, and critique is measured against the stated intent rather than taste drift.

## Pipeline layers · 分层流水线
| Layer | Step | Core modules | Notes |
|---|---|---|---|
| L0 | State intent & constraints | M0, M7 | audience, medium, limits |
| L1 | Reference / moodboard | M1 | curated, not dumped |
| L2 | Explore variations | M6 | many quick drafts |
| L3 | Critique against intent | M3 | does it meet the brief? |
| L4 | Refine & select | M3, M2 | version every iteration |
| L5 | Deliver with versioning | M7 | exports + source files |

## Module combination · 模块组合
- **M0** — volume is not quality; critique against the brief.
- **M1** — load only the references that serve the current direction.
- **M2** — keep every version so any direction can be revisited (M0.9 reversible).
- **M3** — gate: the selected piece satisfies the stated intent and constraints.
- **M6** — creative toolchain minimal and pinned; keep editable sources.
- **M7** — delivery is reviewable; assets are versioned, not overwritten.
- **M8** — client/instructor feedback is an explicit contract (M8).

## Discipline-specific risks · 领域特有风险
- **Output volume substituted for progress**.
- **Lost versions** — no way back to a stronger earlier direction.
- **Misreading feedback** as a mandate to change everything.
- **Inconsistent delivery** (missing sources, wrong formats).
- **Taste drift** away from the original intent.
