## Non-negotiables · 底线
- **No source, no claim.** Every free-tier number links to the provider's own page with an access date.
- **No credential-sharing / proxy APIs.** "Unlimited frontier models, no API key" is a red flag, not a free tier.
- **Free ≠ safe.** Many free tiers train on your data; never send secrets, PII, or proprietary code without checking the data policy.
- **Verify before adoption.** Free tiers and licenses change weekly; this is a snapshot, not a contract.
