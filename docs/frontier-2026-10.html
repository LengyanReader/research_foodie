4 · Per-capability notes · 逐项说明

context-budget-policy

The 2025–26 context-engineering thread (Anthropic [R52]) gained an empirical spine: Chroma's

and even coherent haystack structure measurably degrading results. The harness implication is not "bigger windows" but a policy: write durable facts outside the window (M2), then select / compress / isolate per call, and compact only against a named, measured constraint.

untrusted-content-discipline

The lethal trifecta [R42] is now joined by institutional guidance and an architectural defense. OWASP's Top 10 for Agentic Applications for 2026 (ASI01–ASI10) [R86] routes goal hijack, tool misuse, memory poisoning and rogue agents through one lens; the MCP Security Best Practices spec [R87] makes confused-deputy, token passthrough and local one-click installs concrete, testable failure modes; CaMeL [R88] shows a policy layer can keep untrusted data out of control flow. The capability keeps the discipline minimal:

durable-execution

resumable-memory externalizes knowledge; this capability externalizes execution semantics. Temporal's Durable AI [R90] is the clearest statement: a worker crash must replay a journal to the last committed step, not re-run the day — and that is only crash-safe if side effects are idempotent, because a checkpoint is not an exactly-once guarantee. METR's time-horizon work [R89] supplies the reason this is now load-bearing rather than theoretical: the 50%-completion horizon keeps extending.

cost-budget-caps

Willison's Oct 3 2026 post [R85] — hard caps on pay-by-usage services, default-on, with a prominent "remove the cap" opt-in — is the newest idea in this batch. It is small, sharp, and actionable. The existing sandboxed-execution covers what may run; this covers when it must stop, which nothing else did.

eval-driven-development

LLM-as-a-judge and matches human baselines). OpenTelemetry's GenAI semantic conventions [R91] standardize how a run is traced (invoke_agent → chat → execute_tool), so the evidence exists to grade a trajectory. The capability ties M3 (verified done) to M5: each recurring failure becomes a frozen golden case, and the judge is never the author.

5b · Deliberate non-match · 不匹配说明
