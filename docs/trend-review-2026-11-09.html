Prediction (T5): reproducibility reports will start requiring environment fingerprints (pinned dependencies + hardware + seeds), isomorphic to this library's trial_projects bindings.

agent capabilities + Responses API + Codex compatibility — model vendors now compete on execution-ecosystem compatibility, not only on scores. No November release as of this window.
